## 🔄 Proceso de Actualización

```bash
# 1. Backup
Copy-Item "%LocalAppData%\MARTE\Data" "Desktop\Backup"

# 2. Descargar v1.3.0
# https://github.com/AndyAgurto/Proyecto-Marte/releases

# 3. Ejecutar instalador
.\install-marte.ps1

# 4. Responder "S" para sobrescribir

# 5. ¡Listo! Datos preservados automáticamente
```
